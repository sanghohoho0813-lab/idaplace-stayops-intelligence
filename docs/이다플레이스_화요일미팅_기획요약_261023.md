- 기술개발/공급 법인: **(주)이다플레이스**. `응용 소프트웨어 개발 및 공급업`을 주력으로 정비하려는 계획 단계.
- 실증/운영 예정 법인: **(주)이다컴퍼니**. 숙박시설 인테리어·시설자금 관련 준비 중. **개업 및 숙박 매출 실적 없음(현재 확인 범위)**.
- 제품: **StayOps Intelligence — 숙박시설 개업 준비부터 무인 운영까지 연결하는 AX**.
- 성장 논리: 자사/관계사 현장 테스트 → 실사용 로그·운영개선 → 외부 소형 숙박시설 B2B 공급 → 반복매출/성장자금 평가 근거.

## 대표 앞에서 보여주는 것
1. **개업 준비관리**: 공사/시설/도어락 점검/비품 체크리스트 → 모바일 직원 입력 → PC 준비 상태 즉시 업데이트.
2. **미래 운영 시뮬레이션**: 샘플 예약 → QR 체크인 → 본인확인 → **DEMO 임시 출입 PIN** → 체크아웃 → 청소업무 배정 → 완료 → 객실 준비 상태.
3. **AI 운영 코치**: 개업 준비 지연, 객실 점검/청소 지연 등 규칙 기반 운영위험 감지 → 담당자 조치 → Proof Event 기록.
4. **고객용 모바일**: 실제 소비자가 사용할 것처럼 정교한 QR 예약 확인·입실 안내 웹 UX.

## 반드시 말해야 할 사실
- 현재 호스텔 운영 전이며, 실제 객실가동률·숙박 매출·고객후기는 없다.
- 이번 QR·PIN은 **실물 도어락 미연동 시뮬레이션**이다. 실장비 자동발급은 공식 API/지원 모델/계약/장애·야간 대응 검증 후 구현.
- 필스토리·벤디트는 문제 해결 방식과 제품 성장경로의 벤치마킹이다. 화면·코드를 복제하지 않는다.
- 개발 시스템의 구현/실증은 금융기관 지원을 보장하지 않는다. 실사용 증빙·상용화 계획과 평가 적격성은 별도 준비.

## 단계별 구축 논리
- **시연 MVP**: 개업 준비 실제 업무 입력 + 가상 예약/체크인/PIN/청소 Closed Loop.
- **1차 상용화**: 운영시설 개업 후 실데이터 연동, 개인정보/인증, 예약 채널/도어락 업체의 공식 연동 승인, 운영 모니터링/비상대응 준비.
- **2차 제품화**: 외부 소형 숙박업체 시범운영, SaaS 테넌트 분리·과금·AI 고도화, 향/관광 등 NEXT 기능은 시장검증 뒤 확장.
